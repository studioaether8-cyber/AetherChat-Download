# Aether Chat

Мессенджер для Android.

## ⬇ [Скачать AetherChat.apk](https://github.com/studioaether8-cyber/AetherChat-Download/releases/latest/download/AetherChat.apk)

1. Нажми ссылку выше: скачается файл **AetherChat.apk**.
2. Открой его на телефоне и нажми **«Установить»**. Если телефон спросит, разреши установку из этого источника (браузера или «Файлов»).
3. Открой **Aether Chat**, зарегистрируйся и общайся.
